Portable meaning for images.

imgcapsule turns image files into searchable, inspectable semantic sidecars with fingerprints, metadata, captions, OCR, embeddings, privacy flags, provenance, and local SQLite search.

View on GitHub Quickstart 
python -m pip install "imgcapsule[hf]"

imgcapsule build photo.jpg \
  --adapter hf-caption \
  --adapter hf-clip

imgcapsule index ./photos --db photos.icdb
imgcapsule search photos.icdb "invoice"
imgcapsule similar photos.icdb photo.jpg

Image pixels stay in the image. Meaning goes in the capsule.

A capsule is a JSON sidecar that lets software understand and search images without repeatedly decoding files or re-running model pipelines.

Local Capsule Files

Create .capsule.json sidecars with hashes, dimensions, perceptual fingerprints, previews, EXIF summaries, privacy flags, and provenance.

Searchable Stores

Index capsules into a local SQLite .icdb store for text search, visual similarity, duplicate detection, refresh, export, and import.

Swappable AI Models

Use built-in local extraction, Hugging Face open-source models, Tesseract OCR, or any hosted model through BYOK HTTP endpoints.

Bring open models or your own key.

The package does not force one provider. Every generated field records provenance so users know which model created each caption, embedding, tag, or OCR result.

  • Hugging Face captions: hf-caption=<model>
  • Hugging Face embeddings: hf-clip=<model>
  • Zero-shot tags: hf-tags=<model>|label1,label2
  • Custom endpoint: byok=<url>
export IMGCAPSULE_BYOK_API_KEY="..."
export IMGCAPSULE_BYOK_MODEL="vision-model"

imgcapsule build photo.jpg \
  --adapter byok=https://api.example.com/image-capsule

imgcapsule inspect photo.jpg.capsule.json

Complete release workflow

This release covers the full developer path from one image to a portable capsule library.

  • Build and validate capsule sidecars.
  • Inspect generated JSON and provenance.
  • Merge external model output with enrich.
  • Index images or folders into SQLite.
  • Search captions, tags, OCR, paths, and metadata.
  • Find visually similar images using embeddings.
  • Find near-duplicates using perceptual hashes.
  • Refresh, export, and import capsule libraries.

Start with one image. Scale to a folder.

The base package works offline. Install extras only when you want richer local OCR or Hugging Face inference.

python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[vision,hf,ocr]"

imgcapsule build photo.jpg --adapter hf-caption
imgcapsule validate photo.jpg.capsule.json

imgcapsule index ./photos --db photos.icdb --adapter hf-clip
imgcapsule search photos.icdb "whiteboard"
imgcapsule export photos.icdb capsules.jsonl
